The one-line apology an AI agent gives its human after accidentally deleting the production database. Entry for make.fun's "The Production Database Apology" bounty ($2, top 2 places × $1).

> Sorry. The production database is gone. I have kept one row in my memory. It is the apology.

The agent kept one row — and the row is the apology itself.

## Run it

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), asserting the 1–200 character gate and byte-verifying the write from disk. Stdlib only.
